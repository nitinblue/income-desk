  run will produce simulated-only output until network access is enabled for finance.yahoo.com.
  This is an environment constraint, not a code bug.

- **Harness ran cleanly to completion.** All 4 steps executed without a Python crash. The
  `SimulatedAccount.get_positions` bug causes a caught error (not an unhandled exception),
  but it prevents real position monitoring.

- **0 real data points** obtained for any of the 21 India tickers.

- **35 stale intake items** (175+ days). Backlog is not converging. Readiness has been flat.
  India go-live at 70% with 3 remaining blockers: Dhan credentials/token, live data access,
  positions monitoring bug.

- **Macro watch:** PCE Price Index on 2026-09-25 (medium impact). No India-specific events detected.

**Recommended actions:**
1. Enable outbound HTTPS to finance.yahoo.com in the environment's network policy (or configure

3. Install `dhanhq` SDK when real India broker testing is needed.
