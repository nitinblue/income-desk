## Errors & Blockers

### P0: Network / Proxy Block (Root Cause of All Failures)

- **All yfinance fetches fail** with HTTP 403: "CONNECT tunnel failed" through the environment proxy.
- This is a hard blocker for India market data: every ticker, every index, every macro instrument (^NSEI, ^NSEBANK, SPY, ^VIX, etc.) returns the same error.
- **Impact:** Regime detection is impossible, scan returns 0 candidates, environment context is simulated only.
- **Action needed:** Proxy must whitelist `query1.finance.yahoo.com` / `finance.yahoo.com`, or an alternative India data source (NSE API, Dhan historical API) must be wired.

### P1: Dhan Broker Not Connected

- `DHAN_CLIENT_ID` and `DHAN_TOKEN` env vars not set; no `~/.income_desk/broker.yaml` with `dhan:` key.
- Without broker: live quotes unavailable, positions cannot be fetched, option chain data is absent.
- **Action needed (Nitin):** Set Dhan credentials in env or config before live trading.
